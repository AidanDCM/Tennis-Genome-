# API-Tennis Trial Usage Budget

This project will not treat the advertised provider ceiling as a target.

Initial admission stage:

- Probe 001: exactly 1 request.
- No further requests until Probe 001 evidence is inspected and a specific research role is approved.
- No polling loops.
- No odds/market requests.
- Each future capture workflow must declare and enforce its maximum provider-call count before execution.
- Historical bulk collection must be resumable and content-addressed before a multi-call run is permitted.
- Production champion behavior remains independent of this source until a challenger passes preregistered validation.

The purpose of this budget is to preserve the API-Tennis trial for high-information calls rather than exhaust capacity on exploratory crawling.
